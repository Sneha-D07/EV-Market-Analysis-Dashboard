# EV Market Analysis Dashboard

## Project Overview
An interactive Excel dashboard designed to analyze the Electric Vehicle (EV) market, exploring vehicle pricing, range, ratings, sales trends, brands, and specifications.

## Dashboard Preview

![EV Market Dashboard](EV%20Market%20Analysis%20Dashboard/Dashboard_Preview.png)

## Key Performance Indicators (KPIs)
- Average Price
- Average Range
- Average Rating
- Annual Sales

## Dashboard Features
- Interactive slicers for Year, Brand, Country of Origin, and Variant
- Top 10 Brands by Sales
- Sales Trend by Model Year
- Distribution by Drive Type (AWD, FWD, RWD)
- Country of Origin analysis
- Variant comparison
- Battery Capacity analysis

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Dashboard Design

## Objective
To transform EV market data into an interactive dashboard that helps users explore trends, compare brands and vehicle variants, and gain insights into the electric vehicle market.
